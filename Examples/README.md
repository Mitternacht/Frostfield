# Frostfield examples

No sample application is implemented yet.

The first planned example is a UIKit app that renders one programmable scene through
`MTKView`, exposes native controls for scene parameters, and handles resize and lifecycle
changes. Add reference captures and a repeatable physical-device profiling route with
that implementation. Later examples can cover custom materials, particles, and
post-processing.

The executable work and acceptance gates are listed in [the backlog](../tasks/todo.md).
